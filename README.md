## 📚 Danh Mục Các Buổi Thực Hành

### 🔹 Thực Hành 1 (TH1): PHP Cơ Bản & Lập Trình Hướng Đối Tượng (OOP)

## 🚀 Hướng Dẫn Chạy Bài Tập

### 1. Chạy trực tiếp qua dòng lệnh (CLI)
Mở Terminal tại thư mục gốc và chạy file mong muốn:
```bash
php TH1/bai1.php
php TH1/bai2.php
php TH1/bai3.php
php TH1/bai4.php
```

### 2. Chạy trên Trình duyệt Web (qua XAMPP)
1. Mở **XAMPP Control Panel** và bấm **Start** ở module **Apache**.
2. Mở trình duyệt và truy cập các địa chỉ tương ứng:
   - `http://localhost/web/TH1/bai1.php`
   - `http://localhost/web/TH1/bai2.php`
   - `http://localhost/web/TH1/bai3.php`
   - `http://localhost/web/TH1/bai4.php`
